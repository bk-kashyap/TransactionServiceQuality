29. Retry policy

     Recommended:

          | Failure                | Retry?      |
          | ---------------------- | ----------- |
          | Assertion failure      | ❌ No        |
          | Schema mismatch        | ❌ No        |
          | Wrong HTTP status      | ❌ No        |
          | Business-rule failure  | ❌ No        |
          | Connection reset       | ⚠️ Possibly |
          | HTTP 502/503           | ⚠️ Possibly |
          | Infrastructure timeout | ⚠️ Possibly |
          | Browser/process crash  | ⚠️ Possibly |

     And importantly:
     A retry does not turn the original failure green.

     Report:
          FAILED FIRST ATTEMPT
          PASSED RETRY
     as an intermittent result.
