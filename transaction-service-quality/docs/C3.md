scripts/contract.cjs reads YAML and compiles original definitions with AJV. validate-contract.cjs validates structure/references with Swagger Parser. src/validators/schema.validator.ts connects request/response validation to the definitions. Duplicated Zod schemas were removed: they strengthened presence rules while weakening integer IDs. Validator tests assert wrong-type rejection and empty-object acceptance exactly where supplied schemas allow it.

Hearsay comparison: positive input and server-applied sign partly match prose; complete direction/unit/type mapping is not formalized. Rupees-to-minor-unit storage, 10-14 digits, idempotency, request IDs and atomic audit writes are not formal commitments. Independent request/response examples are not evidence of an implemented round-trip.

## Consumer contracts

Mobile needs account identity, operation/sign/type, caller-unit money, stable rejection causes and replay semantics. Specify only interactions/fields it consumes, with consumer-owned provider states and boundary examples. The ledger transport is not given: confirm HTTP versus events before defining it; do not invent an event bus. Its needs include transaction identity, account association, explicit currency/units, timestamp, ordering/duplicates and reliable read/delivery.

Publish versioned consumer contracts to a broker. Provider CI verifies supported deployed consumer versions against a real provider with controlled states; a compatibility/can-I-deploy gate blocks incompatible deployments. Additive optional fields may be compatible; unit/sign changes or removed consumed fields are breaking. Pact implementation is optional; this is a written design, not a running integration.

## Mock drift

Preserve supplied YAML digest and validate responses against it; keep reference policy separate. On staging run contract checks, approved behavior and consumer verification. Compare real statuses/shapes/headers/semantics with spec and policy, and require versioned provider evidence before updating fixtures. Never change a spec/mock merely to make a provider failure green.
